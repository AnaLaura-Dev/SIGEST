# Sistema de Gerenciamento de Estágios Técnicos
Voltado para automação de todo o processo de estágio para Institutos Federais do Amazonas
Disponível em: https://sigest.site.je/
---
### Usuário Aluno
* Realiza candidatura e acompanha candidatura
* Editar perfil
* Anexar curriculo
* Acompanhar documentação de estágio
* Anexar documentos de estágio e acesso a informações para validar o estágio
* Visualizar desempenho
---
### Usuário Empresa
* Cadastra vagas
* Visualiza candidaturas
* Acessa perfil do aluno com informações do curriculo e curso
* Seleciona candidatos
* Adiciona desempenho do aluno
---
### Usuário Instituição
* Gerencia vagas
* Valida documentação do aluno
* Acompanha processo do estágio
---
